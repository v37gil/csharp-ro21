# СРСП 1. Перевод секунд в часы, минуты и секунды

## 1. Словесная запись алгоритма
1. Запросить у пользователя ввод целого неотрицательного числа секунд.
2. Проверить корректность ввода: если строка не является целым числом или число меньше 0, вывести сообщение об ошибке и завершить работу.
3. Вычислить количество часов путем целочисленного деления общего количества секунд на 3600: $H = S / 3600$.
4. Вычислить остаток секунд: $S_{rem} = S \% 3600$.
5. Вычислить количество минут путем целочисленного деления остатка на 60: $M = S_{rem} / 60$.
6. Вычислить оставшиеся секунды: $Sec = S_{rem} \% 60$ (или $S \% 60$).
7. Вывести результат в формате `H ч. M мин. Sec сек.`.
